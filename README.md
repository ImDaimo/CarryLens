# Carry Lens

Installers for **Carry Lens**, a League of Legends companion and in-game overlay for Windows.

**Download:** open [Releases](../../releases/latest) and run `CarryLens-Setup-<version>.exe`.

Carry Lens updates itself: when a new version is out, an **Update** button appears in the app's top bar.

This repository holds installers only.
